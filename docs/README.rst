Documentation Directory
=======================

This directory contains the generated HTML documentation for the PurpleAir API project.

Directory Structure
-------------------

::

   docs/
   ├── html/              # Latest documentation built from main
   ├── html_v*/           # Versioned release documentation (HTML format)
   ├── _static/           # Landing page static assets (Furo theme, CSS, JS)
   ├── _sources/          # Landing page source files
   ├── .nojekyll          # Disables Jekyll processing for GitHub Pages
   └── index.html         # Landing page with version selector

Generated Documentation
-----------------------

The ``docs/`` directory contains both the root landing page (generated from ``sphinx_docs_build/landing``)
and versioned documentation directories (generated from ``sphinx_docs_build``).

Viewing Documentation
---------------------

Local Viewing
~~~~~~~~~~~~~

Open ``index.html`` in your web browser:

.. code-block:: bash

   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   
   # On Windows
   start index.html

GitHub Pages
~~~~~~~~~~~~

The documentation is available on GitHub Pages at:
https://carlkidcrypto.github.io/purpleair_api/

Rebuilding Documentation
------------------------

The documentation is built from the source files in ``sphinx_docs_build/``:

.. code-block:: bash

   # Build main docs (into docs/html)
   cd ../sphinx_docs_build
   make clean
   make html

   # Build landing page (into docs/)
   cd landing
   make clean
   make html

Versioned Documentation
-----------------------

Versioned documentation directories (``html_v*``) are generated automatically on release
via GitHub Actions (``.github/workflows/sphinx_build.yml``).

Files in This Directory
-----------------------

.nojekyll
~~~~~~~~~

This file tells GitHub Pages not to process the documentation with Jekyll.
This is important because Jekyll ignores directories starting with underscores,
which would break Sphinx's ``_static/`` and ``_sources/`` directories.

index.html
~~~~~~~~~~

Sphinx-generated landing page with links to all released documentation versions.

html/
~~~~~

Contains the latest HTML documentation built from ``main``. These files **are committed to git** and
deployed to GitHub Pages.

doctrees/
~~~~~~~~~

Contains Sphinx's internal cache files. This directory is not committed to git
(excluded via ``.gitignore``) as these are build artifacts that should be 
regenerated when needed.
