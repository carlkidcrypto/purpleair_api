PurpleAir API Documentation
===========================

The **PurpleAir API (PAA)** library is a modern, robust, and well-maintained Python 3 wrapper
for the official `PurpleAir <https://www2.purpleair.com/>`_ sensors and air quality sensor data API.
It simplifies querying real-time and historical air quality metrics (PM1.0, PM2.5, PM10,
temperature, humidity, and atmospheric pressure) with built-in rate-limiting and error handling.

Key Features
------------

* **Comprehensive API Coverage:** Query single sensors, multiple sensors, and historical sensor data.
* **Automatic Rate Limiting:** Built-in request pacing to comply with PurpleAir API rate limits.
* **Error Isolation:** Resilient network handling and custom exception hierarchies for dependable air monitoring.
* **Typing & Validation:** Fully typed with Python dataclasses and validation checks.
