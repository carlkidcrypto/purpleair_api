PurpleAir API - Java Bindings
=============================

Java bindings for the PurpleAir API using the native C++ library via SWIG and JNI.

Prerequisites
-------------

- SWIG 4.x or later
- g++ with C++17 support
- libcurl development headers (``libcurl4-openssl-dev``)
- Java Development Kit (JDK) 11 or later (e.g. OpenJDK 21)
- Meson (>=0.64.0) and Ninja

Building
--------

The build process uses Meson/Ninja to generate SWIG JNI wrappers, compile the
native shared library (``libpurpleairapi_base_java.so``), and compile the Java
classes into ``purpleair-api.jar``.

From the repository root:

.. code-block:: bash

   meson setup builddir
   ninja -C builddir

Running Tests
-------------

You can execute the Java test suite via Meson:

.. code-block:: bash

   meson test -C builddir java_tests -v

Usage
-----

.. code-block:: java

   import com.purpleair.api.*;

   public class Example {
       public static void main(String[] args) {
           // Create Read API instance
           PurpleAirReadAPI readApi = new PurpleAirReadAPI("your_api_read_key");

           // Request single sensor data
           String sensorData = readApi.request_sensor_data(1234);
           System.out.println(sensorData);

           // Request local sensor data
           StringVector ips = new StringVector();
           ips.add("192.168.1.100");
           PurpleAirLocalAPI localApi = new PurpleAirLocalAPI(ips);
           String localData = localApi.request_local_sensor_data();
           System.out.println(localData);
       }
   }
